# ATOM GARDEN v0.19 — 반응 연결망

나무 시약 선반과 픽셀 원자를 사용하는 브라우저 샌드박스입니다.
`index.html`을 브라우저로 열면 실행됩니다. npm 설치, 외부 자산, API 키가 필요 없습니다.
기존 브라우저의 저장 데이터 형식을 유지합니다.

## ZIP 실행·GitHub 업로드

1. ZIP을 **압축 해제**합니다.
2. `index.html`과 모든 `.js`, `laboratory.css`를 같은 폴더에 둡니다.
3. `index.html`을 Chrome/Edge/Firefox로 열면 실행됩니다. Node.js나 서버 설치가 필요 없습니다.
4. 친구에게는 ZIP 전체를 보내세요. 친구도 압축을 풀고 실행해야 합니다.

GitHub에는 ZIP 자체 대신 **압축을 푼 폴더 안의 파일 전체**를 올립니다.
`index.html`이 저장소 최상위에 오게 하세요. 새 `reaction-data.js`와 `reaction-engine.js`를 반드시 포함해야 합니다.
기존 게임 파일은 이번 파일로 교체합니다. 예전 파일에 새 JS만 추가하면 실행 순서·버전이 맞지 않습니다.
`tests/`, `docs/`, README는 게임 실행에 필수는 아니지만 전체 업로드해도 됩니다.
GitHub Pages는 Settings → Pages에서 배포 브랜치와 루트 폴더를 선택합니다.
이 ZIP 업로드가 기존 브라우저의 보안 경고 판정을 자동 해제하지는 않습니다.

## 구현 범위

- 원소 도감 **118종**, 별도의 물질·이온 도감 **333종**.
- 이 중 **207종 염**은 양이온·음이온의 전하로 화학식 계수를 정합니다.
- 새 공통 엔진 **584개 방향별 규칙**. 반응 수첩은 기존 산소·연소·물 반응을 포함해 **619개 등록 경로**를 보여 줍니다.
- 정방향/역방향, 해리/결정은 각각 한 경로로 셉니다. 기존 자유 원자 결합·산염기·금속 치환 등의 모든 조합 수를 의미하지 않습니다.
- 정확한 등록 목록은 `docs/substances.json`, 검색 가능한 반응 목록은 `docs/reactions.json`에 있습니다.

실제로 존재하는 모든 물질·모든 반응을 예측하는 양자화학 엔진은 아닙니다.
등록한 물질군과 조건을 공유하는 엔진이며, 화학식을 맞출 수 있다는 이유만으로 임의의 화합물을 만들지 않습니다.

CuI₂, FeI₃, AgOH, NH₄OH 및 단순 Al/Fe(III) 탄산염은 생성하지 않습니다.
질산 근처에서 기존의 일반적인 금속+산→H₂ 경로가 잘못 작동하지 않도록 구분했습니다.
질산의 다른 금속 반응과 진한 산의 생성물 경쟁은 미구현입니다.

## 바로 확인하기

1. 왼쪽 아래 **개발자 모드**를 켭니다.
2. 위쪽 **반응 수첩**을 열고 실험 키트를 고릅니다.
3. **실험대에 추가** → 수첩이 닫히면 **재생**을 누릅니다.
4. 오른쪽 관찰 기록에서 반응식과 생성물을 확인합니다.

키트는 질산 은+염화 나트륨, 염화 바륨+황산 나트륨, 탄산 칼슘+염산,
에탄올 연소, 탄산 칼슘 열분해, 염산+아세트산 나트륨의 6종입니다.
기존 입자를 지우거나 가열하지 않고 중앙에 시약을 추가한 뒤 일시정지합니다.
다른 실험이 중앙에 있으면 상호 반응할 수 있으므로 이동 도구로 공간을 확보하세요.
개발자 실험은 발견 기록을 늘리지 않습니다. 일반 모드에서 생성한 물질은 발견 후 재소환할 수 있습니다.

수첩은 화학식·한글 이름·반응 종류로 검색합니다. 아래 **물질** 선반에는 산·염기·염·유기물·이온 필터가 있습니다.
철 산화는 실제 철 원자 4개와 O₂ 3분자를 가까이 배치하고 게임 온도 1,000 K 부근에서 확인할 수 있습니다.
메테인은 CH₄:O₂ = 1:2, 에탄올은 C₂H₅OH:O₂ = 1:3입니다. 배경 공기는 반응물 산소를 대신하지 않습니다.

## 정확성의 범위

원자 ID·원소·동위원소, 화학 반응 전후의 총 전하와 전자 수를 보존합니다.
한 입자가 동시에 여러 생성물에 들어가지 않도록 반응물을 확보한 뒤 전체 반응을 적용합니다.
고체의 이온결합 표시는 개별 분자가 아니라 조성 단위를 묶은 근사입니다.
전자 전하는 계산 장부이며 실제 전자 밀도·분자 궤도·결합 각도를 의미하지 않습니다.

반응 속도·접촉 반경·열량·분해 온도·압축 조건은 **게임 매개변수**입니다.
새 유기물의 800 K 연소 기준은 공통 게임 설정이며 각 물질의 실제 발화 온도가 아닙니다.
발열 장부는 화학 반응의 원자/전자 보존과 별개이며 전체 에너지 보존 시뮬레이터는 아닙니다.
촉매는 소비하지 않지만 반응 중간체와 촉매 표면을 해석하지 않습니다.

용해도는 수용성·난용성·불용성 3분류입니다. 난용성은 주변 물 8분자를 경계로 사용하는 게임 근사이며
Ksp·실제 농도·정량 포화도를 계산하지 않습니다. 기존 Ca/Sr 수산화물의 물 해리는 완전 해리 근사를 유지합니다.
약산의 정량 평형과 pH, 착물·배위화학, 이성질체, 고분자, 생화학, 광화학, 전기분해, 모든 방사성 붕괴는 미구현입니다.

새 염·고체의 기본 상태 표시는 250–400 K, 자료가 없는 새 유기물의 대표 상태 표시는 290–300 K로 제한합니다.
이 범위는 실제 녹는점/끓는점이 아닙니다. 범위를 벗어나면 **자료 없음**으로 표시하고 등록된 반응은 계속 판정합니다.
일부 기본 분자·알코올과 기존 물질은 별도 상변화 자료를 사용합니다. 기존 산화물은 별도 모델 범위가 있습니다.
118개 원소 모두의 핵합성은 구현하지 않았으며 일반 모드의 신규 원소 생성은 기존 항성 순반응 경로에 한정됩니다.

## 구성과 검사

- `reaction-data.js`: 물질군, 용해도 분류, 허용/제외 조합, 균형 반응식.
- `reaction-engine.js`: 주변 반응물 탐색, 조건·촉매 판정, 원자/전자 보존, 반응 수첩·실험 키트.
- 기존 `physics.js`, `ions.js`, `acid-base.js`, `oxidation.js` 등은 공통 엔진과 연결됩니다.
- 자동 저장은 각 브라우저/주소에 보관됩니다. 다른 주소나 다른 PC로 자동 이동하지 않습니다.

압축을 푼 폴더에서 Node.js로 검사합니다. 실행 자체에는 Node.js가 필요 없습니다.

```sh
node tests/physics.cjs
node tests/energy-light.cjs
node tests/combustion.cjs
node tests/oxidation.cjs
node tests/reaction-network.cjs
```

333종의 저장·불러오기/전하, 584개 규칙의 원자·전자 배정, 실제 침전/중화/분해/연소/치환,
촉매·온도·물 조건, 혼합 용액의 600단계 운동, 발견/개발자 키트 보존을 검증합니다.
브라우저에서 실제 BaSO₄ 침전, 시약 필터/검색, 반응 수첩을 확인했습니다.
